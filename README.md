## 🎯 Overview

This project combines traditional academic management with a natural-language analytics layer.

```text
Student Records
     ↓
Attendance + Marks
     ↓
Analytics / Dashboards
     ↓
Natural-Language Queries
     ↓
Actionable Academic Insights
```

## ✨ Features

- 🔐 Multi-user / role-based access
- 👨‍🎓 Student record management
- 📅 Attendance tracking
- 📝 Marks and subject performance
- 📊 Analytics dashboards
- 📈 Progress summaries
- 📤 Report/export workflows
- 🤖 Natural-language data queries
- 🗃️ MySQL-backed records

## 🛠️ Tech Stack

**Frontend:** HTML • CSS • JavaScript

**Backend:** PHP

**Database:** MySQL

**AI:** Generative AI / natural-language analytics

## 🚀 Getting Started

1. Clone the repository.
2. Configure a PHP + MySQL environment such as XAMPP.
3. Import/configure the database.
4. Configure application credentials.
5. Start Apache/MySQL.
6. Open the application through your local PHP server.

Never commit real API keys or database credentials.

## 🧩 Architecture

The system separates academic data management from the analytics/query layer so the dashboard can continue working while AI-powered querying is treated as an additional capability.
